##########
User guide
##########

weatherbroadcaster provides a small HTTP API for retrieving cached weather
data from Rubin Observatory.

The service reads a JSON cache generated by the weather update command and
returns the contents from the ``/weatherbroadcaster/data`` endpoint.

Endpoints
=========

``GET /weatherbroadcaster/``
    Return service metadata.

``GET /weatherbroadcaster/data``
    Return the latest cached weather data. If the cache has not been created
    yet, the service returns ``503 Service Unavailable``.

Data format
===========

The response is a MeteoBlue-compatible payload containing station metadata,
timestamped weather measurements, and ``-999`` for missing values where
required by the target format.
